# SpendWise

SpendWise is a personal finance application built with React and Vite. This repository currently contains the Phase 1 JavaScript starter; routing, authentication, and finance features will be added in later stages.

## Requirements

- Node.js 20.19 or newer
- npm

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build and lint

```sh
npm run build
npm run lint
```
